성분의 기능을 확인하세요.

사진에서 읽은 성분명을 확인한 뒤, 직접 학습한 SVM으로 6가지 기능을 예측합니다.

STEP 1 · 선택 사항

내 피부 타입

피부 타입별 관리 목적과 예측된 기능을 연결해 안내합니다. 타입을 선택하지 않아도 성분 분석은 가능합니다.

STEP 2 · 성분표 준비

사진을 찍거나 선택하세요

영문 INCI 성분표를 정면에서 선명하게 촬영해 주세요. 한글을 읽을 수는 있지만 영문 성분명으로 자동 변환하지는 않습니다.

사진의 글자 인식은 브라우저에서 처리합니다. 첫 실행에는 OCR 파일 다운로드가 필요합니다.

STEP 3 · 확인 후 분석

읽어낸 성분명을 확인하세요

OCR 원문 확인 · 다시 편집하기

쉼표와 줄바꿈 분리가 정확한지, 철자가 맞는지 확인해 주세요. 한글 성분명은 영문 INCI 이름으로 직접 수정해야 합니다.

검증 데이터에서 예측이 맞은 사례입니다. 전체 성능을 대표하지 않습니다. 입력을 편집하면 예시 성분 안내만 유지됩니다.

RESULT · 직접 학습한 모델과 관리 기준

내 피부 타입과 연결되는 기능

성분 기능은 학습한 SVM의 추정이고, 피부 타입 연결은 자료를 참고한 개발자 규칙입니다. 함량·제형·개인 반응은 반영하지 않으며, 개인 적합성이나 효과를 보장하지 않습니다.

성분별 모델 예측

TF-IDF + Linear SVM · 피부 보습 / 피부 유연화 / 피지 조절 / 피부 보호 / 수분 증발 억제 / 불편감 완화
OCR은 기존 도구를 사용하며, 기능 분류는 직접 학습한 모델을 사용합니다.
